Firewall distribué — MultiNetworkPolicy

Définissez le contexte, les security groups et les flux : les objets YAML sont générés à la fin.

1. Contexte

Où les règles s'appliquent : le namespace des pods et le réseau secondaire (NAD) filtré.

    2. Security groups

    Un groupe = une ou plusieurs IP / réseaux. Les pods du namespace sont rattachés à un groupe par le label neos/vm.dfw-sg, sur lequel les règles sont posées.

      3. Flux autorisés

      Chaque flux autorise une source à joindre une destination sur des ports. Tout ce qui n'est pas listé est bloqué pour les pods filtrés.

        4. YAML généré

        Un objet par security group et par sens : jamais d'ingress et d'egress dans la même MultiNetworkPolicy.
