Firewall distribué — MultiNetworkPolicy

Définissez le contexte, les security groups et les flux : les objets YAML sont générés à la fin.

1. Contexte

Où les règles s'appliquent : le namespace des pods et le réseau secondaire (NAD) filtré.

      2. Security groups

      Un groupe = une ou plusieurs IP / réseaux. Les pods du namespace sont rattachés à un groupe par le label neos/vm.dfw-sg, sur lequel les règles sont posées.

        3. Flux autorisés

        Flux Est/Ouest entre security groups : un ingress et un egress dans deux objets séparés.

          4. YAML généré

          Est/Ouest : un ingress sur la destination et un egress sur la source, dans deux objets distincts. Nord/Sud (si coché) : un seul objet avec ingress et egress.

              
  
              

              



              
  
              5. Schéma des flux
              
  
              Flux autorisés entre les security groups, le network et la gateway. Chaque couleur correspond à un flux de l'étape 3.
